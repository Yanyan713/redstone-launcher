    Serveurs Multiplayer
    
        
    Rejoins tes serveurs favoris en un clic.
    
      
    
      
    
        
        
        
      
    
      
      
      
      Choisis d'abord une version et un compte dans l'onglet « Jouer », puis clique « Connexion rapide ».
      
    
      

    
    
      
      
      
        
      Comptes
      
        
      Comptes locaux (hors-ligne, éducatif) ou Microsoft.
      
      
      
      
      
      
      
        
      Ajouter un compte local (hors-ligne)
      
        
      
          
          
        
      
        
      Le compte local ne nécessite aucune connexion (mode hors-ligne,
          idéal pour une utilisation éducative / en classe). Tu peux lui ajouter un skin
          (bouton « Skin », fichier PNG 64×64 ou 128×128).
      
        
      Compte Microsoft
      
        
        
      Le compte Microsoft permet de jouer en ligne avec un vrai profil Minecraft
          (et son skin officiel). La connexion se fait sans mot de passe : chaque personne
          saisit elle-même ses identifiants sur la page Microsoft — le lanceur ne stocke jamais
          de mot de passe.
      
        
      
          
      
            
      Va sur  et saisis le code :
      
            
      
          
      
        
      
        
      
      
      
    
      

    
    
      
      
      
        
      Minecraft Bedrock Edition
      
        
      Version Bedrock (Windows) — resource packs et lancement.
      
      
      
      
      
        
      
          
      Minecraft Bedrock n'est pas installé sur cet ordinateur.
      
          
      Bedrock est disponible gratuitement si tu possèdes Minecraft Java
            (compte Microsoft lié). Sinon, achète-le sur le Microsoft Store.
      
          
        
      
        
      
          
      
            
      🟩
      
            
      
              
      Minecraft Bedrock
      
              
      
            
      
          
      
          
          
      Bedrock se lance avec ton compte Microsoft connecté au Store.
            Aucune connexion supplémentaire n'est nécessaire dans le lanceur.

      ou clique pour choisir
